# Documentation

Swiftel is a local Rust CLI for bounded public-source research. The repository is [Swiftelligence](https://github.com/bobvasic/Swiftelligence); the crate and executable remain `swiftel`.

- [Servo browser runtime](runtime/SERVO.md) — optional non-Chrome rendering, actions, local prompt planning, and isolation.
- [Network and parser boundaries](security/BOUNDARIES.md) — what is enforced and what is not.
